## Execution realism

These strategies generate signals; this audit adds no broker order placement. A candle-close price is not automatically an obtainable fill: the bar completes, data arrives, evaluation runs and the user must act. Backtests must use the earliest defensible post-signal price and include bid-ask spread, slippage, brokerage, taxes/transaction fees, market liquidity and gap-through-stop risk.

AOU-OSS uses a configured round-trip friction assumption (default code value 7.5 bps) and L2 spread gate; CRSD has pair-cost configuration. Those are code assumptions, not verified current all-in charges. Other strategies do not demonstrate positive expectancy after cost simply by generating stop/target levels.

## Robustness gates

Use multiple relevant symbols and regime segments; keep chronological development, validation and untouched out-of-sample data; include realistic execution timing/costs; examine parameter sensitivity, repeated signals and look-ahead; and report trade count, win rate, average win/loss, expectancy, profit factor, max drawdown and regime/symbol stability. No performance metric is available from this source-only review.

## Overall conclusion

No strategy is proven profitable or production-ready. ORB, CPR, Dual EMA, APEX, AOU-OSS and CRSD have interpretable but unproven hypotheses. Sector Impulse has confirmed technical defects in the baseline. SSF has parameter-provenance and stateful-feed risks.
